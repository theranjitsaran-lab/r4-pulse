# R4 Pulse

A four-screen management tool for R4 Services (Pulse, Activity, Pricing, Calls, with Margin as a
drill-down), built by StepsGrowth on Node, Express, vanilla JS and inline SVG, reading a
DigitalOcean Postgres database refreshed daily from VCK and Veri-Shred.

Start with `CLAUDE.md`, then `DECISIONS.md`, then `STATUS.md` for where the build stands.
`PROMPTS.md` is the build sequence.

The application code, `docs/` and the corrected versions of these files are still in the local
repo on Theran's laptop and are to be pushed here. See `STATUS.md`.
